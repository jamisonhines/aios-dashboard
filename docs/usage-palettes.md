# Recency-prioritised, co-occurrence-safe usage palettes

Computed and validated: 2026-10-01. Executable hex values and retained-model bindings: `usagePalettes.mjs`. Fix round 2 supersedes whole-window-share folding and individual local colours.

## Recent priority, one export-wide plan

`usageRanking.mjs` is the pure ranking rule shared by runtime and offline search. The recent interval is exactly seven export calendar dates, ending on the latest date in the complete export. It uses UTC calendar arithmetic on serialized date keys, not the host clock or selected range. Each provider's models sort by:

1. Provider-relative input + cache read + cache write + output token share in those seven dates.
2. Whole-export provider-relative share, only when recent shares tie.
3. Model key, only when both shares tie.

Retired models with zero recent use rank behind models with positive recent use, regardless of their old volume. `computeUsageColorPlan(stats.days, settings.usageModelColors)` runs before range selection; both chart modes, legend and model table reuse that same plan. Range or view changes cannot repaint it. The UI discloses the exact recent interval and current tails.

All local models use one `Local` chart group, one violet colour, and zero cost. Their individual names and four token buckets remain in the model table, labelled `(Local)`, not `Local other`. Local group membership ignores recency and model count.

## Same offline engine, broader capacity search

`dev/search-usage-palettes.mjs` keeps the deterministic hue/lightness/chroma grid, farthest-point restarts, and coordinate-ascent objective. The objective maximises minimum normal-vision OKLab Delta E subject to Machado 2009 severity-1 protan/deutan Delta E >=6. Candidate hue, band and chroma are measured after sRGB gamut projection.

Hue ranges are non-overlapping: Claude 310..360 and 0..100, OpenAI 130..285, Local 290..<310. The single Local slot is violet, outside Claude's warm magenta range. Candidate filtering enforces these limits independently of the sampling grid.

To avoid over-folding along one greedy path, the search now enumerates every Claude/OpenAI capacity allocation in descending retained-individual count, with Local fixed at one slot. It evaluates all allocations at the first feasible count. Ties prefer balanced provider retention, then recent-share coverage, then minimum normal separation. Fixed budgets are 16 restarts/1 ascent pass for >12 displayed colours and 96/3 for <=12. Pair distances are cached as Float64 values; scoring and gates are unchanged. This remains a bounded heuristic search, not a proof of global optimality.

On calibration, 23 allocations were tried. None with ten or more individual cloud models passed both modes. The winning allocation retains nine: five Claude and four OpenAI, plus their provider Other groups and one Local group. Hex values are committed, never generated by the plugin. Retained known identities keep explicit slots; retained unknown identities take persisted next-unused provider steps. Folded members share only their authorised provider Other identity.

Reproduce with private data and temporary output, without committing usage data:

```sh
node dev/search-usage-palettes.mjs path/to/private-export.json /tmp/usage-palette-result.json
node dev/validate-usage-palettes.mjs path/to/private-export.json /tmp/aios-dataviz/validate_palette.js /tmp/usage-palette-evidence.md
```

## Verification

`usageRecentPalette.test.mjs` proves recent activity outranks old volume, seven-date boundaries, export-date anchoring, both tie-breaks, stable filtering/view changes, Local grouping and named Local table rows. `usagePalettePairs.test.mjs` retains the all-pairs gates, identity stability, cost/token conservation and overflow proofs. Shipped renderer tests cover both chart hosts and named membership suffixes.

The external canonical validator runs `--pairs all` on each provider, the combined palette and every actual day's co-occurring displayed groups, in both modes. The report records every run, deterministic reproduction, the new retained/folded lists with seven-day shares, and any zero-recent-use facts. No account totals or transcripts are stored in this public document or fixtures.
